# 中英双版与分发兼容设计

日期：2026-11-02；目标版本：0.2.0。延续用户已明确的 GitHub 公开分发、使用者自带 AI、无需作者运营后端的范围。

## 用户可见结果

保留 `musk-decision` 中文技能和原有完整指令入口，新增独立 `musk-decision-en`，其指令、方法、来源摘要、输入模板、示例与安装说明均为英文。两版使用相同 M01–M06 证据和行为原则。根文档提供语言切换和分别安装的路径，不把仅翻译 README 当成双版。

## 分发接口

`release.json` 记录项目名、默认版本语言和各版的技能目录、指令标题与参考路径。无配置时保留原打包接口与文件名。默认生成中文；`--edition en` 生成英文；`--all` 生成两版。共用源码 ZIP，分别输出安装 ZIP 与可独立粘贴的完整指令，不依赖另一语言目录。

保留隐藏目录、凭据、符号链接和 Windows Junction 防护。配置、缺失文件与本地引用在创建输出前校验。复用标准库构建器供第二个独立项目使用，不引入服务器或模型 API。

## 验证

保留原12项回归，新加英文安装与内联内容、源码文档、配置边界、双版输出测试。中文版本维持已经验证的功能；独立试答检查英文输出、数字建议、引用和用户约束。公开前做一次独立整体审查。

毛选独立源码项目存放在被父仓库忽略的 `projects/mao-selected-works-skill`，单独构建源码包；公开使用的技能同步到根 `skills/mao-practice`，说明置于 `docs/mao-practice.md`，三个下载文件置于 `downloads/mao/`。这样可复用现有仓库写入权限，同时避免递归打包本地项目或旧分发包。
