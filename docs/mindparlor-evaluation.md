# MindParlor 0.1.0 preview 验证记录

日期：2026-11-03。Windows 本机，Python 3.12.4，标准库。以下明确区分内容结构、程序验证、代理试聊与未完成的人类/跨宿主验证。

当前范围仅为 MindParlor 中英双语十人聊天。用户后续明确要求删除全部无关旧功能，并将仓库改名为 `Mj-usst/mindparlor`；改名已核验，Git 历史保留。下述旧版测试与初次打包结果单列为历史证据，不代表当前树仍包含旧功能。

## 构建与程序

- 当前测试只覆盖保留的 MindParlor 功能。实施者和整合者分别运行 **25项测试，全部通过，0跳过**：原有15项 MindParlor 测试，加10项发布边界回归；包含实际创建的 Windows junction 检查。整合者另通过十个人物、二十份提示的目录检查。
- `scripts/mindparlor.py` 使用本项目的 `scripts/release_support.py`，无需已删除的工具。回归覆盖独立 CLI 运行、私有/隐藏文件排除、输入与输出 junction、二进制输入与 BOM、版本校验、引用式 Markdown 链接和越界链接等。
- 清理后已实际重建并同步23个公开下载文件，逐项核对清单 SHA256；在全新临时目录解压65个安装文件，并从解压副本重编译全部20份提示，与源码和单文件下载一致。提示 ZIP 的20个条目与单文件一致，重复构建逐字节相同。仅 `skills/mindparlor/` 与 `downloads/mindparlor/` 保留为功能及下载入口，当前 Markdown 本地链接全部有效。

这些程序检查确认文件、引用和构建行为，不能证明人物观点正确或语气还原度。

### 初次实现的历史证据

- 原仓库基线为26项测试通过。最初12项 MindParlor 测试曾因运行入口尚不存在而失败，实现后通过。
- 实际发现 Windows 管道中文输出采用 GBK，新增字节级回归复现失败后修正 CLI 为 UTF-8。独立审查另复现导出覆盖输入文件和中文邻接来源编号漏检，均新增回归并先失败后修正。
- 清理前的组合测试为 **41通过，0失败，0跳过**，包括现已移除的26项旧功能测试和15项 MindParlor 测试。这不是当前测试数量或旧功能兼容承诺。
- 初次发布准备实际执行了 `python scripts/mindparlor.py check`、`build` 和官方 skill 格式检查。全新临时目录解压验证65个安装文件与十个人物，解压副本重编译结果、二十份提示与 ZIP 条目、全部 SHA256 均一致。此处记录当时结果；本轮来源文件变更后需重新构建产物。

## 内容规模与来源

- 十个人物；中英文各自有语言指南和示范。
- **70条来源记录**，不是70个独立证据背景；同一人的多篇文本也不等于跨情境观察。
- **160组原创多轮示范**：每人每种语言8组，每组4条发言。中英文情境多有配对，不应视作160次独立效能试验。
- 来源作者实际打开相关正文并记录范围、日期、定位、转录/编辑性质与失败访问；没有把只读文字说成听过录音。独立审查只对沃什、塞勒、乔布斯部分来源再次作了现场抽查，没有复核全部70条。
- 毛泽东按历史文本重建，补核中文《实践论》《矛盾论》和《游泳》原文；不声称复刻口音或自然私聊。
- 凯文·沃什的任职与2026年本人讲话有核查记录；历史讲话与当前立场分开。塞勒的身份不是比特币创始人，个人主张与公司行为分开。

来源详细局限分别见每人的 `sources.md`、[金融组记录](mindparlor-finance-author-report.md)、[历史组记录](mindparlor-history-author-report.md)与[技术组基线及范围说明](mindparlor-tech-baseline.md)。

## 实际试聊与独立审查

- [开发基线](mindparlor-tech-baseline.md)：只给姓名的定性试答，保留实际原文；不是未受污染的对照实验。基线本来就能区分部分人物并拒绝编造内部消息，因此没有声称新 skill 必然改善这些能力。
- [独立试聊原文](mindparlor-behavior-smoke.md)：十个场景，十个人都有实际生成的回应；另有一段连续20个用户轮次的中文脚本，在毛泽东与特朗普之间切换并返回。
- 试聊可观察到不同的判断重心、不同意用户、无建议的闲聊和原话来源澄清；同时出现一次替用户补写猫已离开的细节，下一轮被纠正。已加窄范围连续性规则，但不据此宣称永不幻觉。
- 试聊和静态审查共同发现单人物提示缺少换人范围说明；已修复，并用新代理上下文仅载入单人物文件作定点复测，具体原文见[中文定点复测](mindparlor-single-prompt-retest-zh.md)与[英文定点复测](mindparlor-single-prompt-retest-en.md)。
- [独立代码与内容审查](mindparlor-final-review.md)：两处可复现程序缺陷和一处指令契约缺口已修复；原始审查和整合处理均保留。

## 仍需如实保留的局限

所有人物均为 **preview**。没有完成双语真人盲测、十人各两段20轮的系统性长聊、第三方无工具聊天宿主测试、不同模型版本的全面兼容或真实用户留存研究。新代理上下文仅加载单文件，仍不等于真正取消了其工具权限。

人物的日常情绪与私下幽默常只能从公开表达外推；轻松闲聊中仍可能出现过于精巧的笑话或相似的体贴顾问口吻。Jobs 的企业发布文案支持产品展示取向，不能单独证明本人的私聊口吻。后续应以用户不看名字的普通聊天比较来验证差异，而非堆来源数量或声称百分比保真度。

本版本的用途是让用户现在能试用并提供具体反馈；这些限制不隐藏在“测试全过”的表述后面。

## 定点复测与本机安装结果

英文六轮及中文七轮在仅加载各自单人物完整提示的新代理上下文完成。两者没有声称读取缺失人物资料，未编造猫的跳跃方向，并区分新写句子和历史原话。中文仍有“它看它的”这类轻微场景推测，已如实留在原文。英文后续复测也未承诺安装完整版就一定含有泰勒这一未收录人物。该后续复测沿用同一评测上下文，不称为再次独立采样。

初次验证时，65个安装文件曾在本机新增的用户 skills 目录安装并逐字节核对，格式验证通过，未覆盖当时其他本机技能；下载目录包含23个文件。这是本机安装的历史记录，不表示仓库继续提供其他技能。后续仓库清理、改名和发布不扩大这里记录的模型验证范围。
