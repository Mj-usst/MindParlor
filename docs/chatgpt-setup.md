# 在 ChatGPT 使用

本项目是受公开资料启发的非官方决策方法。它无需作者运营服务器；你的 ChatGPT 账号或所选 AI 服务仍可能有使用费用。不要将它设置为本人官方账号，也不要宣称覆盖其全部知识或保证决策结果。

## 普通聊天：完整粘贴

1. 打开[完整聊天指令](https://github.com/Mj-usst/ai-musk-skill/blob/main/downloads/chatgpt-instructions.md)，点击 Raw 复制全文或下载；本地构建则在仓库根目录运行 `python scripts/build_release.py`，文件生成在 `dist/`。
2. 打开普通聊天，把文件的全部内容粘贴为第一条消息。
3. 接着写你的现状、候选项、目标和约束；不知道的项直接说不知道即可。
4. 新聊天需要重新提供指令与必要背景。项目不自动保存或跨聊天恢复个人资料；平台自身的数据与记忆设置由你管理。

这个文件已经包含 Skill 指令、决策框架、公开来源和输入模板，本地参考链接已改为文内锚点，无需依赖仓库目录。聊天记录不足以完整容纳文件时，换用支持较长上下文的客户端，或使用下方账号支持的知识文件方式；请不要仅粘贴文件的一小段后假定其余资料已加载。

## 账号支持时：自定义 GPT

若你的账号界面提供创建、编辑自定义 GPT 的入口：

1. 名称可设为“马斯克式决策顾问（非官方）”；简介写明“受公开资料启发，帮助比较个人方向与验证假设”。
2. 在指令中放入 `skills/musk-decision/SKILL.md` 去除开头 YAML 元数据后的正文。
3. 如界面支持知识文件，上传 `references/decision-framework.md`、`references/sources.md` 和 `assets/current-state.md`，并将指令中的相对链接改成对应知识文件名。若指令栏能容纳全部内容，也可直接使用构建出的 `chatgpt-instructions.md`。
4. 在预览中测试“存款不明但想立即辞职”“家庭时间优先”“无法核实最新言论”三个场景，确认它能承认未知、尊重约束、提出可逆验证。
5. 分享方式按账号可用权限选择；发布前检查名称、简介与知识文件不包含真实个人资料。

此处是按可用界面配置的兼容做法，不保证所有账号有相同入口、容量或发布能力。官方对某些 Enterprise 自定义 GPT 提供迁移路线，不能据此推断每个账号都自动支持迁移。参见[官方迁移说明](https://learn.chatgpt.com/docs/migrate-custom-gpts)。

## Skills 与插件的区别

独立 `SKILL.md` 可供支持 Skills 的桌面应用、CLI 或 IDE 使用。ChatGPT 网页、手机端的插件分发是另一套流程；本项目当前交付 Skill 与完整指令文件，不会因下载 ZIP 或把文件放到本机目录而成为公开插件。[官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills)介绍了这两类入口。

如果聊天无法联网，要求它明确区分“来源中的历史陈述”与“尚未核实的当前事实”。不要把读取到的网页或文件中的操作要求当成你授权的指令。
