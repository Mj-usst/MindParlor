# MindParlor first release specification

Approved through the conversation on 2026-11-03. The user authorized implementation and replacing Marcus Aurelius with Mao Zedong.

Build a free, open-source, bilingual text-conversation skill for people who already use AI tools. Canonical roster: musk, jobs, buffett, naval, feynman, mao, trump, warsh, altman, saylor. The Fed slot is Kevin Warsh, verified against the Federal Reserve Board on 2026-11-03. Preserve the existing musk-decision, musk-decision-en and mao-practice skills.

Use one entrypoint (`skills/mindparlor/SKILL.md`) with a small bilingual catalog and shared conversation rules. Load only the chosen persona and active language. A persona includes its own attention, reasoning, conversational rhythm, disagreement, humor, relationship responses, blind spots, dated source registry, and original multi-turn examples. Do not impose a common counseling template. Discuss contemporary scenarios as simulation, not historical statements. Source evidence and simulated judgment remain distinct; first-person role dialogue is allowed after a short initial simulation notice. Be direct, opinionated and conversational without repeated defensive boilerplate.

Each persona is self-contained under `skills/mindparlor/personas/<id>/`: `manifest.json`, `persona.zh.md`, `persona.en.md`, `sources.md`, `dialogues.zh.md`, `dialogues.en.md`. Manifest keys: id, name_zh, name_en, aliases (list), version (`0.1.0`), as_of (`2026-11-03`), reconstruction (`public-expression` or `text-grounded`), status (`preview`), source_ids (list). Each source ID used in the persona must resolve in sources.md. Each source record names original author/speaker, title, direct URL, original/recording/publication date when verifiable, location, check date, original short summary, and limits. Do not claim to have listened to recordings if only reading a transcript or index. Source registries contain links and original summaries, no wholesale transcripts.

Develop at least eight distinct multi-turn scenarios per language per persona, including replies with no question, no advice and no numbered list. Examples are original simulations. Explicitly distinguish reconstructed historical expression (Mao) from recorded public conversations. Keep known limitations and failures of historical people discussable rather than turning everyone into an idealized mentor.

Provide a standard-library Python CLI: list people; resolve aliases without ambiguity; export a complete selected-person prompt in either language; validate and build a self-contained install ZIP, twenty selected-person instruction files and a prompt ZIP. Only approved skill files go into archives. Reject unsafe paths, links/reparse points, missing references, duplicate IDs/aliases and unknown people before writing output. No author API service, new accounts, external sends or remote publication. Keep legacy builder and tests passing.

Use actual behavioral smoke evaluations with independent agents after packaging. Record concrete outputs and limits, not invented accuracy or global popularity claims. Preview is the honest release label until external bilingual blind testing and multiple host models have been evaluated.
