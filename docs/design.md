# AI 马斯克决策 Skill：首版设计

日期：2026-11-02。用户在三组需求回答后授权继续处理实现。

## 目标和选择

为中文用户提供一个可在 GitHub 分发、无需作者运行服务器的 Skill，帮助梳理个人现状、职业和创业方向。重点是有依据地分析决策，不追求扮演本人。

考虑过：ChatGPT 自定义 GPT（使用方便，但入口与发布能力依账号而定）；独立网站（需承担服务和模型调用运营）；公开 Skill（用户使用自己的兼容客户端，作者无需运营后端）。采用用户最后指定的 Skill，另提供可粘贴到 ChatGPT 的完整指令作为兼容入口。

## 首版范围

- 名称 `musk-decision`，中文展示名“马斯克式决策顾问”。
- 独立 SKILL.md、界面元数据、可追溯的精选来源、决策方法和现状输入模板。
- 中文 README、虚构示例、MIT 许可、自带标准库打包命令和行为评估记录。
- 交付安装用 ZIP、GitHub 源码 ZIP、ChatGPT 完整指令文件。
- 不训练模型，不收集完整生平，不运行爬虫或自动更新，不部署网站或订阅服务。

## 行为契约

首次简短说明为非官方方法模拟。将用户事实、关键未知量、模型判断和人物来源分开。可直接给出有条件的建议，避免无休止盘问；关键缺口最多集中问三项，并先做可以完成的分析。

比较现状、用户候选项和可行的过渡路径；评估现金流、时间、能力、需求证据、家庭责任和可逆性。建议的金额、时限和门槛要标明是可协商的模型建议，不冒充普遍规律。输出推荐、取舍、最大不确定性、改变结论的证据、下一步验证和复盘条件。尊重用户已有的生活价值与限制。

第一性原理和工程优化从原始资料归纳；选项比较、个人现金流和验证计划是项目编写的通用工具。公司愿景、本人陈述和实际发生的结果分开。未来结果不保证，当前事件需查证，无联网时注明缺口。

不收集无关身份资料；不默认保存对话、跨会话记忆或向 GitHub 上传个人现状。文件导出由用户请求触发。Skill 本身不附带交易、发送信息、辞职等外部行动权限。

## 验证与交付

先用无 Skill 对照回答定位真实缺陷，再用相同任务测试新指令。加测资料不足、引用核验、价值约束和资料注入情境。官方快速校验验证技能格式；标准库单元测试验证打包完整性、独立指令可用性和不打包私人目录。行为试答是有限样本，不视为效果保证。
