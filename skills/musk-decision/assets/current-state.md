# 我的现状与方向问题

按愿意披露的程度填写，未知和不想回答都可以留空。可以直接用口语讲述，不必完整填表。无需身份证、账号、详细住址或客户个人资料。

- 我现在要决定的事情，以及最迟何时决定：
- 我希望半年或一年后的生活是什么样：
- 对我最重要的价值与不能牺牲的事情：
- 当前工作或学习状态，最满意和最困扰的部分：
- 已有技能、可展示成果、行业经验与资源：
- 可投入的时间和精力：
- 可依赖收入的大致范围：
- 每月必要开支；是否已经含家庭支持、债务：
- 可用于过渡的资金；其中不愿动用的储备：
- 家庭、健康或其他会影响方案的限制（只填相关的）：
- 已在考虑的方向及喜欢它们的原因：
- 目前有哪些证据、试过什么、实际结果如何：
- 我能承受的失败后果，以及希望避免的结果：

请先总结已知事实和关键未知，比较现状与可行方向，给出当前推荐、改变建议的证据，以及一个低成本验证行动。自拟的数字和门槛请标为可调整建议。
